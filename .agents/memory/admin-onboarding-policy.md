---
name: Admin onboarding choice
description: User-selected Admin creation fields and recipient-chosen passwords.
---

Manage users lets an Admin add Admin and Officer accounts with a Full name,
Username and Email. The recipient chooses their password using a private setup
link; do not replace this with an initial password chosen or generated for the
creating Admin to share. Admin emails must end in `@admin.co.za`; Officer emails
may use any valid email domain. Admin-created Officers are active when added.

**Why:** The user requested Admins be able to add Officers. They previously selected a password setup link for added Admins and emphasized easy username-based sign-in.

**How to apply:** Use the private one-time setup flow for added staff, display the link to the Admin to share, and preserve separate Citizen/Officer self-signup behavior. Automatic email delivery was not part of the agreement.
