---
name: Dashboard location consent
description: Privacy boundary between viewing a live map and requesting emergency assistance.
---

Automatic GPS permission requests on the Citizen Dashboard do not authorise creating SOS alerts or saving a location history. A pause must survive routine data refreshes.

**Why:** This meets the live-map request without treating routine dashboard visits as emergencies or adding background tracking. Browser permission and the Citizen's pause choice remain meaningful.

**How to apply:** Keep dashboard location separate from explicit emergency submission. Show an honest overview when GPS is unavailable, not a fabricated current position. Reconsider consent before introducing stored or server-shared dashboard coordinates.
